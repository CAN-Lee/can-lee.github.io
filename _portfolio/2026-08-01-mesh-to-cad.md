<li><strong>Geometric primitive decomposition:</strong> Recover parametric primitives and constructive solid geometry (CSG) compositions from 3D meshes, using signed distance fields (SDFs) to explore compact, editable shape reconstruction.</li>
<li><strong>Fitting and self-evolving search:</strong> Build a Mesh-to-CSG prototype that jointly optimizes primitive parameters and Boolean structure; explore recursive self-improvement (RSI), using geometry error and program validity to guide agents in refining decomposition and structure-search strategies.</li>
